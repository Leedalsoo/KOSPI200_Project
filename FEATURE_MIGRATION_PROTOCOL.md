For every baseline feature:

1. Identify user-visible/business purpose.

1. Trace actual input/output.

1. Identify external dependencies.

1. Extract invariant domain behavior.

1. Map to Standard Contract.

1. Reimplement in new ownership location.

1. Create isolated deterministic test.

1. Compare with baseline behavior where baseline evidence exists.

1. Record KEEP/CHANGE/BLOCKED decision.

Never migrate a whole folder merely because some files are useful.
